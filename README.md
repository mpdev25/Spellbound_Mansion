# Spellbound_Mansion

## Welcome to Spellbound Mansion

Spellbound Mansion is my first attempt at writing a program by myself. It is a text based adventure that takes place in Katscurse mansion, a mansion that has been placed under a spell by it's sorcerer owner. There is only one way out, will you find it?

# Controls

To play the game follow the onscreen prompts for input options.

The basics are:
* m to move
* c to view character sheet
* e to change equipped items
* q to quit the game

These inputs can only be used outside of combat.

## Requirements

Python3
